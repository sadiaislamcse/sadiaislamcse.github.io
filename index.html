02Method

Four rules every agent ships with.

  1. One brief per agentA master instruction file for the project, one per agent, and shared code modules.
  2. Never start overProgress is saved after every unit of work, so a crash only costs the current row.
  3. Confident or silentData is written only above a confidence threshold. Wrong data is worse than none.
  4. Built for the operatorClear commands, plain notifications and a handover guide for whoever runs it next.
