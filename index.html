02 / Approach
How I build so it keeps working after I leave.

  

    
01
One brief per agent
A master instruction file for the project, one per agent, and shared code modules.

    
02
Crash-proof by default
Progress is saved after every unit of work. An interruption never means starting over.

    
03
Confident or silent
Agents write data only above a confidence threshold. Wrong data is worse than none.

    
04
Written for the operator
Clear commands, plain notifications and a handover guide for whoever runs it next.
